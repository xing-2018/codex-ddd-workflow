# JavaScript and TypeScript routing

Read once for a JS/TS surface. Select only [JavaScript](javascript.md) or [TypeScript](typescript.md) for the changed language; add [React](react.md) only where actually used. These links do not require loading every body. Respect the existing delivery form, module system, compiler/browser target, package manager, routing, state, UI and request libraries. ## Checks

Reuse existing ESLint/Prettier or Biome, type checks and authorized behavior checks. No parallel tool chain, full-repository formatting or automatic strictness migration follows from a local edit. Retain actual asynchronous, state and runtime-boundary protection when simplifying tests.
