# 中文自然度修订

本参考用于深度“去AI味”、中文母语化改写和机械文风诊断。目标不是让文本显得随意，而是让结构、句法和判断像作者围绕真实读者任务作出的选择，而不是模型按固定模板拼接的结果。

## 1. 先锁定不可改变项

修订前确认文档类型、受众、事实、结论边界、术语、命令、数据、引用和用户要求保留的声音。自然度修订不能改变产品行为、设计决定、证据强度或操作顺序。

以下内容通常应保留：

- Runbook中的真实步骤、前置条件、验证与回滚；
- API、字段、状态值、路径、命令和配置的准确写法；
- 为比较、状态或验收服务的表格与列表；
- 法务、合规、标准或组织模板要求的固定用语；
- 原文已经清楚、有信息量且符合文体的句段。

没有用户明确要求时，不套用具体作者的声音，不把正式报告改成聊天体，也不为了“有个性”增加情绪、轶事、反问、金句或未经支持的判断。

## 2. 四层诊断

先查结构，再查段落、句子和表面格式。不要只替换高频词，否则深层模板仍会保留。

### 文档层：主线是否一致

- 标题、摘要、开头、主体和结论是否在回答同一个问题；
- 章节顺序是否符合读者理解或执行顺序，而不是生成时想到什么写什么；
- 是否有单看通顺却不推进主线的“资料卡”段落；
- 结尾是否回应已展开的判断，还是临时拔高、宣布时代变化或重复摘要；
- 多个章节是否反复使用“定义→三项拆解→意义升华”的相同形状。

处理顺序是删去无关内容、合并重复内容、移动错位内容，最后才补写缺失链路。材料不足时宁可收窄范围，不用空话撑出完整架子。

### 段落层：每段是否承担真实功能

为每段标记一个主要功能，例如交代背景、提出判断、提供证据、解释机制、给出例子、限定边界、说明动作。无法命名功能，或与相邻段功能重复时，优先删除或合并。

检查段落是否过度工整：长度接近、起句相似、每段都有三分句、每段最后都下一个更大的判断。自然的节奏来自材料轻重不同，不是随机打乱句式。

### 句子层：关系是否由中文语义自然推进

重点检查：

| 机械信号 | 常见表现 | 修订方向 |
| --- | --- | --- |
| 英文句法直译 | “对于……来说”“基于……”“围绕……展开”“使得……得以……” | 调整主谓和句序，直接写谁做了什么及其结果 |
| 机械对照 | 反复使用“不是……而是……”“不仅……还……” | 保留真实对比；其余改为转折、递进、因果或重心后置 |
| 抽象抬升 | “本质上”“真正重要的是”“归根结底”“这意味着”密集出现 | 直接写机制、约束、影响对象或可观察后果 |
| 空泛大词 | “赋能”“重塑”“颠覆”“显著提升”“高质量发展”没有证据 | 补指标、比较对象、动作和条件；无法落地则删除 |
| 过度缓冲 | “可能在某种程度上产生一定影响” | 明确证据支持的范围和条件，保留一层必要限定 |
| 过度确定 | “必然”“彻底”“完全取代”“唯一选择” | 降到证据允许的判断强度，并写出边界或反例 |
| 路标堆积 | “首先/其次/最后”“与此同时”“值得注意的是”连续使用 | 删去可由上下文推断的路标，让事实和因果承担连接 |
| 预告式收束 | 段尾反复“接下来将”“下一步要讨论” | 改为当前结论、未解约束或直接进入下一节 |

词语本身不是禁用项。只有当它掩盖关系、重复出现或替代证据时才修改；逐词黑名单会产生另一种机械文风。

### 表面层：排版是否暴露模板

- 同级项目是否都使用“粗体小标题+冒号+一段解释”，即使它们并非真正并列；
- 冒号、括号、破折号或引号是否承担了本可由句子完成的关系；
- 标题是否口号化或彼此同构；
- 引号、品牌大小写、日期、术语和标点是否一致；
- 为了显得有结构而拆出的列表，是否让阅读比连续段落更困难。

列表适合真实集合、步骤、字段、状态和验收项。不要因为列表像AI就取消列表，也不要把连续论证拆成列表来制造清晰感。

## 3. 选择改写力度

- **轻度修订**：保留结构和段落顺序，只清理翻译腔、重复路标、空泛词、判断强度和标点问题。
- **中度修订**：合并或拆分段落，调整句序，取消伪列表和重复摘要，但不改变章节职责。
- **深度重写**：重排章节或论证顺序，删除跑题内容，重建从问题到证据再到结论的主线。仅在用户要求重写，或原结构已经妨碍理解时采用。

默认选择能解决系统性问题的最低力度。原文局部已经自然时保留，不把整篇改成同一种“Codex文风”。

## 4. 从结构到措辞修订

1. 用一句内部工作句概括文档要帮助读者理解、决定或完成什么。
2. 对照工作句检查章节和段落功能，先删、并、移，再补必要信息。
3. 修正段落推进，让事实、原因、限制和结果自然相接。
4. 清理句子层的翻译框架、机械对照、抽象抬升和强度失真。
5. 最后统一标点、术语和排版；不要在表面润色阶段引入新事实。

这是工作顺序，不要求在交付物中展示诊断标签或步骤。用户只要改稿时直接交付改稿；只有用户要求解释、评审或对比时，才简要说明最影响阅读的模式。

## 5. 交付前自然度检查

完成一次刻意的可预测性检查：连续阅读三个以上同级章节或段落，判断读者是否能仅凭前文格式预测下一段仍会“定义、列三点、再拔高”。如果可以，回到内容功能调整结构，而不是随机更换连接词。

再确认：

- 第一段提出的任务或问题在结尾得到回应；
- 每个主体段都推进主线或提供必要信息；
- 抽象判断附近有事实、机制、约束或后果；
- 列表、表格和编号都服务真实结构；
- 没有连续的路标、机械对照、口号收束或重复预告；
- 判断强度与证据一致；
- 改写后仍保持原文的事实、术语、文体和授权边界；
- 读出声时句子有长短变化，停顿自然，没有明显翻译腔或演讲稿式排比。

发现问题时只修复能明确说明原因的部分。当文本已经准确、清楚且自然时停止，不为追求“更像人”继续增加个性化表达。
