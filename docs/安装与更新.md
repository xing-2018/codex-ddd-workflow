# 安装与更新

本页面向Windows，由本机Codex获取仓库、核对目标并执行已获准安装。需要Git和可用的Python3.11+；安装工具只使用标准库。Codex应先解析本机Python绝对路径，不假定仓库盘符、用户目录或桌面安装位置。

## 安装范围

| 模式 | 内容 | 目标 |
| --- | --- | --- |
| skills，默认 | 全部7项常驻Skills | 当前用户的`~/.agents/skills/<name>` |
| workflow | 7项常驻Skills和4项角色 | 上述Skill目录及`$CODEX_HOME/agents/`，CODEX_HOME未设置时为`~/.codex/agents/` |
| project | 明确选中的非常驻Skills | 指定项目的`.agents/skills/<name>` |

AGENTS.md不属于工具写入范围。根目录[AGENTS.global.md](../AGENTS.global.md)及[中文审阅版](../AGENTS.global_zh.md)供用户审阅，采用或合并须另行决定准确内容和作用范围。安装不修改config.toml，不清理旧名称或其他安装副本。

## Codex执行步骤

1. 按用户指定目录克隆或更新公开仓库。已有副本含本地改动、分叉或未知来源时停止自动更新；固定公开提交或标签，不切换分支。
2. 用已解析Python绝对路径运行公开安装入口的verify，检查所选版本和Skill目录。来源由用户确认；工具会固定本轮来源内容，写入前再次比较。
3. 创建plan，核对本机目标，展示差异、冲突和备份位置。所有计划放在克隆仓库`.local-artifacts/<本次任务>/`中；计划会含使用者本机路径，不提交或发布。
4. 已有明确授权覆盖同一固定计划且无漂移时执行apply，不重复询问相同批准。未知、较新、同版异内容或本地修改的目标保持不动并报告。
5. 安装前重核完整计划、来源、目标及用户指令／配置哈希。完整备份后复制，核验整个安装单元；任何一项失败时恢复本次已变更目标，并保留失败副本和恢复记录。

以下命令由Codex在仓库根目录执行。`$installPython`须是本机已确认的Python绝对路径，任务路径使用本次真实目录：

```powershell
& $installPython -B scripts/install_public_distribution.py verify
& $installPython -B scripts/install_public_distribution.py plan --mode skills --output .local-artifacts/<本次任务>/plan.json
& $installPython -B scripts/install_public_distribution.py apply --plan .local-artifacts/<本次任务>/plan.json --plan-sha256 <plan输出的SHA>
```

更新仓库后重新生成安装计划，不将旧计划交给新工具。仓库版本见根目录VERSION.txt，各Skill版本见对应目录的VERSION.txt。

完整工作流使用`--mode workflow`。项目模式额外指定`--mode project --project <明确项目绝对路径> --skills <Skill名称>`。这些参数固定范围，不代替用户授权；不为运行工具而修改产品环境。

## 按项目安装请求

```text
请从https://github.com/xing-2018/codex-ddd-workflow获取固定公开版本，将fastapi完整安装到我指定项目的.agents/skills/fastapi。
先核对目标项目版本适用性、同名全局或项目Skill、来源与目标完整哈希，并展示真实目标及备份位置。
授权在已确认项目内按无冲突固定计划安装；保留较新、未知和本地修改的副本，发生漂移时停止相关写入。
不修改依赖、AGENTS.md或config.toml，不安装到全局，不删除其他副本。
```

项目尚未指定时，Codex先询问明确路径。软件／框架不匹配时只报告，不为适配Skill升级项目依赖。

## 更新旧副本

安装时，工具在目标的发现目录之外保存本机安装记录。之后只有记录与旧副本完整内容一致、组件版本确实前进时，才允许自动更新。内容相同直接跳过。

没有记录的旧副本、已修改或较新的副本保持不动；Codex展示差异，由用户决定如何处理，再生成新的计划。不会只比较版本号就覆盖，也不需要获取旧Git历史。原安装工具生成的计划需要重新生成。

记录保存在对应`.agents/installation-receipts/`中；角色记录保存在CODEX_HOME的`installation-receipts/`中。它们属于使用者本机安装，不提交到仓库。计划同时核对记录是否变化，失败时恢复记录及本轮已更改目标。

## 备份与恢复

全局Skill备份位于当前用户`.agents/skill-backups/`，项目Skill备份位于指定项目`.agents/skill-backups/`，角色备份位于解析后的CODEX_HOME下`installation-backups/`。备份位于对应目标的同一文件系统和发现目录之外；每轮使用独立目录。

安装工具移动旧目标、核验备份，再复制固定来源。恢复时将失败副本移动到同轮备份的failed位置，再恢复旧目标；原来不存在的目标恢复为不存在。备份及恢复材料保留，不自动删除。恢复失败时报告具体位置，保留现场，由用户另行决定恢复动作。

文件核验后由Codex报告安装与跳过项、冲突及备份；新会话是否实际发现Skill／角色另行观察，不能从复制成功推定已加载。
