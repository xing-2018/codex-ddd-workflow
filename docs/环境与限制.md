# 环境与限制

本仓库交付Windows版本。macOS、Linux及其他平台需要用户自行修改并验证；本仓库不承诺跨平台安装或运行。

- 管理工具要求Python3.11+和Git，安装工具不需要额外Python包。
- Skills和角色依赖本机Codex提供的实际能力。缺少浏览器、工具、角色入口或插件时，报告限制并使用允许的方法，不静默安装外部能力。
- 文档构建、浏览器验证、视频录制、COM控制和仿真具有各自的软件与版本条件，按Skill核对。字体、排版和模型行为依实际环境变化。
- Femap示例中的版本路径是示例／默认值，须按本机实际安装位置传入`--femap-exe`；示例盘符不属于安装前提。
- LS-DYNA／Femap需要用户自己的软件和合法许可。案例数据、求解器、商业软件和凭据不随仓库交付。
- 英文SKILL.md为执行入口，中文副本用于阅读与审核。只在实际任务需要时读取相关参考。
